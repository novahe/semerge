# 气球控制场景矩阵（上游基线版，2026-08-19）

> 校对基准：合并 WithCheckpoint/stale-RSS 修复**之前**的行为（sandboxer `8aefa22` 基线 + orchestrator 原始 SetSettled/ReclaimSettled）。
> 即：settle/reclaim 裸用 RSS、快照捕获无气球协调——issue #114 所描述问题的原始状态。
> 行号为校对时快照，重构会漂移；以符号名为准。
